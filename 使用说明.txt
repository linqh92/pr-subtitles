文稿 + 音频 → PR 字幕

1. 安装 Python 3.10 或更新版本（推荐 3.12），将工具包解压到可写文件夹。
2. 在该文件夹打开终端，运行：
   Windows：python run.py
   macOS：python3 run.py
3. 先选择只包含口播正文的 TXT 文稿，再选择对应的音频。
   没有可用的文件选择窗口时，会自动改为在终端输入路径。
4. 等待显示“完成”，到本工具的 output 文件夹取 SRT 字幕。
5. 在 PR 中导入 SRT，让字幕起点与这份音频的起点对齐。

本机已安装组件并缓存 small 模型，可直接使用。
换电脑时，首次运行需要联网安装组件、下载模型；以后自动复用。
不要把旧电脑的 .venv 文件夹复制到不同系统，新电脑会自行创建。
这套运行流程全部由 Python 脚本实现，不需要 CMD、PowerShell 或 Shell 启动脚本。
语音识别仍需要安装第三方 Python 组件；脚本会自动完成安装。
重复制作同一份音频，会自动用编号另存，保留旧字幕。
字幕文字以文稿为准，自动识别仅用于确定时间。
文稿和音频差异较大时会停止生成，并保存差异报告。
完成后建议在 PR 中抽查开头、结尾和句子衔接处的同步情况。

默认按标点和每条最多 16 个字符拆分。
需要自行断句时：把 TXT 整理为“一行一条字幕”，运行：
Windows：python run.py --one-line-per-caption
macOS：python3 run.py --one-line-per-caption
只想输入路径，不弹出窗口：在上述命令后加 --terminal。
也可直接提供路径：python run.py --text "文稿.txt" --audio "音频.mp3"
修改字幕长短、指定输出位置或更换模型等操作，见 README.md。

本版已在 Windows 上验证；macOS 已做兼容处理，尚未在 Mac 实机上验证。
